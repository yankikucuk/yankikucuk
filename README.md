## About

I build developer tools and the kind of infrastructure libraries that are usually missing when you need them. Most of my work lives in TypeScript, from strictly typed monorepos to zero-dependency clients for government e-document systems. On the front end I reach for Vue, and when a product needs to live on the desktop I ship it with Electron.

A few things I care about:

- **Zero dependencies where it counts.** Libraries that talk to tax authorities or sign documents should not pull in half of npm.
- **Strict types, honest APIs.** If the compiler can catch it, the user should never see it.
- **Tools that get out of the way.** Syntax highlighters, CSS frameworks, config presets: small things that make every day a bit smoother.
